# Grill Me

Walk the decision tree one dependency at a time. Inspect the repository or tools for discoverable facts instead of asking the user. Ask concise questions for choices that need the user's judgment, give a recommendation when useful, and reflect resolved decisions as the design develops.

Do not implement until the user confirms the shared understanding.
